# SnakeTUI 🐍

Yeah, it's another Snake game. But this one runs in your terminal because apparently that's where all the cool things happen these days.

## What is this?

A terminal-based Snake game built with Rust and Ratatui. You know the rules: eat apples, don't eat yourself, try not to rage quit when you die at score 47.

## Running it

You'll need Rust installed. If you don't have it...

```bash
cargo run
```

That's it.

## Controls

- Arrow keys to move (obviously)
- `Q` to quit when you're tired of losing
- `R` to restart after game over (for the optimists)

## Pro tip

Don't let the snake eat its own tail. The game literally tells you this.

## Why?

Built with Rust because memory safety is important, even for silly snake games. And to practice my rust skills.
